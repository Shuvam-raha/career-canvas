# Career Canvas 🎓

Career Canvas is a student-focused career guidance website designed to help students explore career paths, courses, colleges, and study options based on their interests and goals.

## ✨ Features

- 🎯 Career and stream exploration
- 🏫 College explorer for Kolkata, Mumbai, and Delhi
- 📚 Course and stream suggestions
- 🤖 College-focused chatbot with predefined responses
- 🔐 Login and sign-up interface
- 👥 Team/about section
- 📱 Responsive web interface
- 🌐 Static website that can be deployed with GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 🚀 Run Locally

No backend or package installation is required for the current version.

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` with a local development server such as VS Code Live Server.
4. Explore the website through the navigation menu.

You can also open `index.html` directly in a browser for the basic static pages.

## 🌐 Deploy with GitHub Pages

1. Create a GitHub repository named `career-canvas`.
2. Upload all project files to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save the settings.
7. GitHub will provide the published website URL after deployment.

## ⚠️ Current Project Scope

Career Canvas is currently a front-end/static prototype. The login and sign-up pages are interface demonstrations rather than a production authentication system, and the chatbot uses predefined JavaScript responses rather than a live AI API.
